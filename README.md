# Snowboard & Ski Season 26/27

Pistas en 3D, webcams y calendario de nieve y aperturas de Oberstdorf / Kleinwalsertal, instalable como app (PWA) y usable sin conexión.

Un workflow de GitHub Actions (.github/workflows/update.yml) guarda una imagen de cada webcam a las 6, 12 y 18 h (hora de Alemania), actualiza el pronóstico de Open-Meteo y vuelve a publicar la página.

Datos: AWS Terrain Tiles, Sentinel-2 cloudless 2020 by EOX (s2maps.eu, contiene datos modificados de Copernicus Sentinel), © OpenStreetMap contributors (ODbL), Open-Meteo (CC BY 4.0; ERA5, ECMWF), webcams oficiales de OK Bergbahnen. three.js (MIT).
